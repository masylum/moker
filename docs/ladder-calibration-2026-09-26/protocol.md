# Played calibration protocol — 26 September 2026

The target is an ordering that is consistent with the rarity of constructing and retaining combinations in strategic play. Conditional showdown success, initial-hand potential and game health are secondary diagnostics, not alternative optimization targets. High Card is absence of a combination and excluded from the rarity objective. Overlapping combinations are counted, including folded holdings; ordinary (no Lotus) holdings and removal of each constituent game's last hand are sensitivity checks.

Frozen sources are in `source/`, with SHA-256 hashes in `source-hashes.json`. All variants use these sources throughout the study. Production rules and policy remain unchanged. Basic uses its current nine-category ladder. Advanced adds a five-card suited Long Chow, allowing the matching suit Joker, initially between Three Dragons and Three Dragons + Eyes. Current Lotus reward and three starting sticks remain fixed. Every decision uses 24 equity samples. Ten workers run independent games with deterministic seeds.

Screen: 48 baseline runs in each mode and each primary format (four continuous orbits; four one-orbit games with resets). Test every permitted adjacent swap above Eyes in each mode, 16 continuous runs per candidate, matching the first 16 baseline seeds. This is 20 arms / 448 runs. Structural component/superset constraints remain enforced. Screening is deliberately exploratory; low counts cannot establish rare-category ordering. Existing earlier data is context only, not fresh validation.

Selection: retain the initial order when its rarity objective is zero in both baseline formats and no credible alternative warrants complexity. For observed inversions or uncertain neighbouring groups, examine the relevant swap and, if needed, replay it in reset format or test a combined revision before selection. Prefer orders with smaller rarity mismatch across both formats and minimal changes; inspect any increased all-ins or reduced street-four/showdown frequency. Cap extra selection work at 128 runs. Record selected orders and rationale before opening validation results. This is a local search, not an exhaustive search of all permutations or optimal human strategies.

Validation: 96 fresh runs per selected mode/order in each primary format (384 total). Independent seed prefixes are never used in selection. Additionally validate one-, two- and three-game one-orbit formats with 16 runs per mode and length (96 runs). Four-game coverage comes from the larger primary reset arm. Total planned budget is 928 runs, maximum 1,056 if extra selection is required; stop without claiming certainty if evidence remains insufficient. Do not chase validation noise with repeated changes. Any revised order after validation needs a separately labelled new validation study.

Report all categories, initial best and contained frequencies, initial-to-win potential, retained/newly built counts, showdown counts and fractional hand-win credit, plus resources and health. Quantify adjacent retained-frequency ratios with whole-run bootstrap intervals (4,000 replicates on validation); constituent games stay in their tournaments. Include pointwise 95% and conservative simultaneous intervals across adjacent pairs within each mode/format. Small/all-win categories are not certified just because bootstrap samples are degenerate. Validation formats are reported separately.

Verification: run the existing Dragon/Joker and Long Chow rule probes; check invariants, source consistency and disjoint seeds; independently audit scoring on saved raw holdings; inspect at least ten complete saved game/tournament traces for strategic interpretation. Document existing bot planning limitations and do not describe a bot-only result as proof of human-play equilibrium or a guarantee that every rank is correct.
